# PSUsersTool

PowerShell module to automate user creation.

## Overview

PSUsersTool is a PowerShell module designed to automate User preparation.

The module performs a workflow:
- The parameters validate the existing workgroups in the system.
- Create the new user.
- Add the new user to a group.

## Features

- PowerShell `-WhatIf` and `-Confirm` support.
- Verbose execution output.

## Requirements

- Windows 10, Windows 11, or Windows Server.
- PowerShell 5.1 or PowerShell 7.
- Administrator privileges.
